# Modelling Micelle Formation in a Viscous Fluid
This repository contains the code used to combine pecnut's [Stokesian Dynamics](https://github.com/Pecnut/stokesian-dynamics/tree/master) program with the Quadrature by Expansion method in the [pytential](https://github.com/inducer/pytential) package to solve boundary integral equations, applied to amphiphilic particles with multiple hydrophobic tails.

The repository contains both the Python environment the code is ran on (myenv) and the implementation (stokes_dyn_Janus), and the videos for my MMath report (VIDEOS). The videos are split into the relaxations and videos of (high) shears.
This requires a **Linux** machine for all packages to correctly compile, in addition to a CPU or GPU capable of providing an environment for **PyOpenCl**. Without these, the code for amphiphilic particles will not be able to run.

The interface is modified from the Stokesian Dynamics package.

## Test Run
At the time of writing, bugs in the code lead to memory leaking issues, and as such the recommended way to run the program for many frames is by use of a for loop.
We run the program, and then use a separate program to write vts files representing the graphical output.
In order to read the vts files, a program such as Paraview is necessary.

The data generated by the program may be found in the .zarr format, in outputFolder.

```commandline
python -O run_simulation.py 14 11 0.1 30 fte 5 2 outputFolder 30
python plotting/plot_positions.py 1 0 vtsOutputFolder outputFolder
```
Command line arguments:
 - Position: 14 here corresponds to three particles located on the roots of Unity, with one turned away from the center.
 - Input: 11 is the input for the program to be ran with amphiphilic particles.
 - Timestep: 0.1 is recommended.
 - Number of frames: 30 frames with timestep 0.1.
 - Input values: For our particular usecase, only fte (force, torque, strain) is necessary.
 - Save every 5 frames
 - Number of Hydrophobic Tails: 2
 - zarr Output Folder: outputFolder
 - Field extent for recording the potential: 30
 - vts Output Folder: vtsOutputFolder
 - number of files to plot: 1
 - frame number to begin numbering files at: 0

## Other Setups

### Recommended Initial Positions
 - **10:** 3 particles, with one facing away from the other two.
 - **12:** Use the same setup as the latest folder saved in the outputFolder
 - **13:** A single particle on the origin.
 - **14:** Particles placed on the roots of unity, with ability to specify the radius, or number of colloids.
 - **16:** Vesicle setup for a specified radius - requires more time than there is between Easter and the deadline to configure correctly.
 - **17:** Grid of nxn particles with directors normally distributed about the positive x axis.

### Amphiphilic Inputs
By changing the number of amphiphilic tails, you can adjust the particle.
 - **1:** Janus particle
 - **2:** angel particle
 - **3:** cog particle
 - **4:** lopsided cog particle

Various shear flows can be implemented using an input number higher than 11.

### Example Configuration of a Higher Number of Runs
```commandline
python -O run_simulation.py 14 11 0.1 30 fte 5 2 outputFolder 30
for i in {0..3}; do
  echo "Started simulation run $i"
  python -O run_simulation.py 12 18 0.1 50 fte 5 2 outputFolder 30
done
python plotting/plot_positions.py 5 0 imageOutputFolder outputFolder
```
